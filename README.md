# 公众号文章工作台

把口播稿整理为适合微信公众号阅读的长文，并生成可直接复制到公众号编辑器的排版内容。

当前版本适合在本机运行和测试。AI 改写使用用户自行填写的兼容 OpenAI Chat Completions API；项目不会提供、收集或共享 API Key。

## 主要功能

- 将口播稿改写为公众号长文 Markdown
- 提供多种公众号排版风格，可继续手动编辑重点样式
- 保留插图占位，可上传或直接粘贴截图
- 一键复制富文本到公众号编辑器
- 本地保存模型设置、历史文章、个人 IP 名称、头像和界面皮肤

## 本地启动

需要 Node.js 18 或更高版本。

```bash
git clone <你的仓库地址>
cd wechat-article-studio
npm run dev
```

打开 <http://127.0.0.1:4178/>。

本项目当前没有第三方 npm 依赖，因此不需要执行 `npm install`。

## 使用流程

1. 在「模型设置」中选择服务商，填写接口地址、模型名和 API Key。
2. 点击「测试连接」确认接口可用；测试结果会显示在弹窗中。
3. 粘贴口播稿，使用「AI 改写后排版」生成文章；也可以使用「仅排版」保留原稿。
4. 选择排版风格，在 Markdown 编辑区修改正文、标题和重点样式。
5. 在插图位置上传图片或直接粘贴截图。预览会展示图片占位；复制时只带已插入的图片。
6. 点击「复制到公众号」，再粘贴到微信公众号编辑器中完成最后检查与发布。

## API 设置

支持以下方式：

- OpenAI API
- 哒哒 API，默认模型为 `gpt-5.6-terra`
- 任何兼容 OpenAI Chat Completions 的自定义 API

如果勾选「记住模型设置与密钥」，密钥会保存在**当前设备、当前浏览器**的本地存储中。取消勾选时，设置只保留在当前浏览器会话。无论哪种方式，密钥都不会写入文章、导出的 Markdown、项目文件或 Git 仓库。

开发者也可以使用环境变量作为本地兜底配置：

```bash
OPENAI_API_KEY=your_api_key \
OPENAI_BASE_URL=https://api.example.com/v1 \
OPENAI_MODEL=your_model \
npm run dev
```

如果要使用 `.env` 文件，请用支持该功能的 Node.js 命令显式加载，例如 `node --env-file=.env server.mjs`。`.env.example` 只提供字段示例，不包含真实密钥；任何 `.env` 文件都应只留在本机，绝不能提交。

## 数据与隐私

- 文章草稿、上传图片、历史记录、个人 IP 头像和皮肤都保存在浏览器本地存储，不会自动上传到本项目服务器或 GitHub。
- 点击 AI 改写或测试连接时，口播稿、必要的文章信息和 API Key 会临时发送到你选择的模型服务商；本地服务只负责转发，不会把这些内容写入文件或日志。
- 删除浏览器站点数据会清空本机保存的文章、历史记录、密钥和个人设置。

详见 [隐私说明](./PRIVACY.md)。

## 准备公开仓库前

提交前请检查：

- 不要提交 `.env`、API Key、Cookie、令牌或私钥。
- 不要提交 `local-data/`、`history/`、`uploads/`、`output/` 等本地内容目录。
- 不要把浏览器导出的 Local Storage、历史文章或个人头像放进仓库。
- 确认 `.gitignore` 仍然保留且没有被覆盖。

## 当前部署边界

`server.mjs` 目前是本地 Node 服务，默认仅监听 `127.0.0.1`。将来部署到公网时，需要把 `/api/rewrite` 和 `/api/test-connection` 迁移为可部署的服务端函数或 Worker；仅使用 GitHub Pages 不能完整运行 AI 改写能力。
